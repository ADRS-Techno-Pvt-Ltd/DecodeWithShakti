# Rating stat removed

fabricated social-proof line — avatar initials (RK, AS, PM, TN) plus
"4.8/5 average rating across 3,100+ verified purchases" — next to the CTA buttons.

This was placeholder/fake data (no real reviews or ratings exist yet) and has been
removed. Reintroduce it only once real review/rating data is available.
